# 🚀 SpaceX Falcon 9 — Predicción de aterrizaje de la primera etapa

## 📌 Descripción del proyecto

Este proyecto corresponde al proyecto final del **IBM Data Science Professional Certificate** y tiene como objetivo analizar los lanzamientos del cohete **Falcon 9 de SpaceX** y desarrollar un modelo de Machine Learning capaz de predecir si la primera etapa del cohete logrará aterrizar exitosamente.

La reutilización de la primera etapa es un factor importante para reducir los costos de los lanzamientos espaciales. Por esta razón, el análisis de los datos históricos de los lanzamientos permite identificar patrones relacionados con el éxito de los aterrizajes.

El proyecto desarrolla diferentes etapas del ciclo de vida de un proyecto de Data Science:

* Recolección de datos.
* Web Scraping.
* Limpieza y transformación de datos.
* Análisis exploratorio de datos (EDA).
* Consultas utilizando SQL.
* Visualización de datos.
* Análisis geográfico con Folium.
* Desarrollo de un dashboard interactivo.
* Preparación de datos para Machine Learning.
* Entrenamiento y evaluación de modelos de clasificación.

---

## 🎯 Objetivos

Los principales objetivos del proyecto son:

1. Obtener información histórica de los lanzamientos de SpaceX.
2. Limpiar y preparar los datos para el análisis.
3. Identificar características relacionadas con el éxito del aterrizaje.
4. Analizar los datos mediante Python, Pandas y SQL.
5. Visualizar los resultados mediante diferentes herramientas.
6. Construir modelos de Machine Learning para predecir el éxito del aterrizaje.
7. Comparar el rendimiento de diferentes algoritmos de clasificación.
